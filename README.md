# CodeAlpha Data Analytics Internship 🚀

Welcome to my Data Analytics Internship Portfolio at CodeAlpha!

## Projects

### Task 1 — Web Scraping
- Collected 1,000 books using Python, Requests, and BeautifulSoup.
- Extracted book titles, prices, ratings, availability, and product URLs.
- Exported the collected data into CSV format.

### Task 2 — Exploratory Data Analysis
- Performed data cleaning and statistical analysis using Pandas.
- Created visualizations to explore book prices and ratings.
- Conducted Pearson correlation hypothesis testing.
- Found no statistically significant linear relationship between book prices and ratings (p = 0.3736).

### Task 3 — Interactive Dashboard
- Built an interactive dashboard using Streamlit and Plotly.
- Implemented price and rating filters.
- Added KPI metrics, interactive charts, and CSV download functionality.
